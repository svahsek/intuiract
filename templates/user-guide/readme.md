# User Guide Content Type

User Guide is a Markdown-first remediation content type for existing documentation. It uses
topic-purpose models inspired by concept, task, tutorial, reference, and troubleshooting
practices to review sections without imposing a separate file format.

Use the manifest's `review_and_remediate_skill` to audit, suggest, or apply approved changes.
The target page is the input; no release evidence or generated YAML is required.
