# Connect and Manage Your Account

## Overview

Use account connections to exchange information with an approved external service. This guide
explains how to create a connection, confirm that it works, and resolve common failures.

## Before You Begin

You need an active account, permission to manage connections, and the connection URL supplied by
the service administrator.

## Connect an Account

Create a connection when you need this product to exchange information with an external service.

1. Open **Settings**.
2. Select **Connections**.
3. Select **Add connection**.
4. Enter a recognizable name and the connection URL.
5. Select **Save**.

## Expected Result

The connection appears in the list with a **Connected** status. You can now select it when
configuring an integration.

## Connection Settings Reference

| Setting | Description |
|---|---|
| Name | A label that helps administrators identify the connection. |
| Connection URL | The HTTPS endpoint supplied by the external service. |

## Troubleshooting

### The Connection Shows an Error

**Symptom:** The connection status is **Error** after you save it.

**Likely cause:** The URL is incorrect or the external service is unavailable.

**Resolution:** Verify the URL with the service administrator, then save the connection again.

**Next action:** Contact your service administrator if the error continues.
